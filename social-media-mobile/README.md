# Social Chat App (Static Scaffold)

Starter scaffold for a social media + chat Flutter app (static/mock-only).

Features:
- Global theme with `google_fonts` (Inter)
- Routing with `go_router`
- State container: `flutter_riverpod`
- Reusable components and utilities
- A minimal Welcome screen with fade-in animation

Quick run (PowerShell):
```

flutter pub get

```

Note: The app is static (no backend) and prepared for later screens.
