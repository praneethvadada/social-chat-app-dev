## Troubleshooting

### ❌ FCM Token is null
- Ensure device has Google Play Services installed
- Check internet connectivity
- Verify Firebase project is correctly configured

### ❌ Notifications not received
- Check FCM token is saved to backend database
- Verify notification channel exists (Android)
- Check app has notification permission (Android 13+, iOS)
- Ensure backend is calling Firebase Admin SDK correctly

### ❌ Notifications not showing
- For Android: Check notification channel configuration
- For iOS: Check Xcode capabilities are set correctly
- Verify local notification permissions are granted

### ❌ Build Fails
- Run `flutter pub get`
- Run `flutter clean`
- Check pubspec.yaml versions match

## Security Notes

⚠️ **IMPORTANT**: 
- Never commit Firebase service account key to version control
- Store it in environment variables or secure config files
- Use appropriate IAM roles for your service account
- Always validate FCM tokens before trusting them
